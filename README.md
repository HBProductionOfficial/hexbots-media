# hexbots-media

Transient public hosting so Meta can fetch video files.

Instagram publishing does not accept uploads. It takes a URL and fetches the
file itself, so a video has to be publicly reachable for the minute or two that
takes. Facebook accepts the bytes directly and does not need this.

Files are uploaded here as release assets, fetched by Meta, then deleted.
Nothing here is permanent, and everything that passes through is already public
on YouTube.

Managed by ShortsStudio/scripts/lib/host.mjs.
